# Работа с проектом

Перед изменениями читать PROJECT_STATUS.md и проверять git status.

Это самостоятельный проект учебной библиотеки, а не экзаменационных карточек. Предметы и материалы распределяются по расписанию соответствующего курса. Не переносить сюда ведомости и контакты студентов.

Для задачи преобразования документов Word в HTML обрабатывать только материалы 1-го и 2-го курсов. Содержимое, страницы, файлы, привязки и оформление материалов 3-го и 4-го курсов не изменять.

Задания должны быть только из переданных материалов преподавателя, с указанием источника. Не придумывать упражнения, проверочные вопросы, критерии или дополнительные требования. Готовые ответы и составленные по ним конспекты сохранять в авторском архиве, не публиковать их в dist.

Сохранять полные тексты и исходные документы. Не выдавать отсутствующие материалы за готовые. Для изменения содержания редактировать content/library.json; оформление — assets/. Не редактировать сгенерированный dist/ вручную.

Перед сборкой установить зависимости (`npm install`). После изменения запускать npm run build, npm run check и git diff --check. Для правок JavaScript дополнительно node --check изменённых скриптов.

Публикация ещё не настроена. Не добавлять Git remote, не создавать удалённый репозиторий и не публиковать сайт без команды пользователя.

По явной команде пользователя материал истории Церкви переработан в самостоятельное учебное изложение. Публикуется church-history-study; исходные 39 вопросов и ответов остаются в авторском архиве. Не обозначать редакционное изложение как лекцию преподавателя.
