# Работа с проектом

Перед изменениями читать PROJECT_STATUS.md и проверять git status.

Это самостоятельный проект учебной библиотеки, а не экзаменационных карточек. Данные только 3 и 4 курсов; принадлежность предметов подтверждена расписанием. Не переносить сюда ведомости и контакты студентов.

Задания должны быть только из переданных материалов преподавателя, с указанием источника. Не придумывать упражнения, проверочные вопросы, критерии или дополнительные требования. Готовые ответы и составленные по ним конспекты сохранять в авторском архиве, не публиковать их в dist.

Сохранять полные тексты и исходные документы. Не выдавать отсутствующие материалы за готовые. Для изменения содержания редактировать content/library.json; оформление — assets/. Не редактировать сгенерированный dist/ вручную.

После изменения запускать npm run build, npm run check и git diff --check. Для правок JavaScript дополнительно node --check изменённых скриптов. Зависимостей нет.

Публикация ещё не настроена. Не добавлять Git remote, не создавать удалённый репозиторий и не публиковать сайт без команды пользователя.
