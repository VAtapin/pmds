# Статус проекта

## Реализовано

- Главная страница и отдельные справочники `/dogmatika/` и `/nravstvennoe-bogoslovie/`.
- В догматике сохранены 103 вопроса: 65 для 2 курса и 38 для 3 курса. Нравственные материалы в этот справочник не входят.
- Нравственное богословие включает все 32 темы и 96 пунктов предоставленной программы: первый год / 2 курс — 35 вопросов, второй год / 4 курс — 61 вопрос.
- Формат карточки: исходный вопрос, «Запомнить», краткий ответ на несколько предложений, источник. Ответы составлены по рекомендованной литературе; историческая периодизация и девятичинная схема отмечены как учебные схемы программы.
- Общий код справочников поддерживает независимые переключатели учебных блоков, поиск по вопросам, памяткам и ответам, фильтры тем и аккордеон.
- Интерактивный урок `/kto-moi-blizhnii/` сохраняет 13 этапов, отдельные входы учителя и ученика, QR-подключение, пульт и синхронизацию через PHP с премодерацией. Подробности — в README урока.

## Текущее состояние и решения

- Сайт состоит из автономных файлов `dist`; владелец самостоятельно копирует их на сервер.
- Локальная ветка — `main`. Remote и upstream отсутствуют; push невозможен без их настройки. Пользователь подтвердил ручную публикацию вместо push.
- По разрешению пользователя прежние незакоммиченные изменения убраны; база — локальный commit `4bee131`. Перед очисткой сохранена резервная копия в `C:\Users\atapi\AppData\Local\Temp\pruefung-backup-b015cf602dc14fd9ac5c48c76f6f8276`.
- Новая страница использует общие `dogmatika/app.js` и `dogmatika/styles.css`. При ручной публикации нужно обновлять их вместе с `dogmatika/index.html`, главной страницей, `hub.css` и каталогом нового предмета.
- Node используется локально для сборки данных и просмотра; для публикации статического справочника npm, Composer и migrations не нужны.

## Известные ограничения

- Файл нравственного богословия содержит тематическую программу, а не экзаменационные билеты или готовые ответы.
- Удалённую Git-версию и состояние сервера сверить невозможно: remote отсутствует, серверный путь не указан. Production в этой задаче не обновлялся и не проверялся.
- `extract-word-doc.py` поддерживает нешифрованные DOC с обычными потоками и 512-байтовыми секторами; мини-потоки и иные неподдерживаемые структуры явно отклоняются.
