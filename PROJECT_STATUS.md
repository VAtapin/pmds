# Статус проекта

## Реализовано

- Создан отдельный проект учебной библиотеки для 3 и 4 курсов на основе материалов pmds (исходное состояние 6f76acb).
- Главная страница и два самостоятельных каталога: 16 предметов 3 курса и 17 предметов 4 курса, с преподавателями и датами из расписания 2026–2027.
- Учебные главы по восьми предметным разделам; непрерывное чтение, оглавление, поиск, печать, исходные документы и аудиозапись.
- Сохранены 38 тем догматики 3 курса; 16 развёрнутых и 48 прежних тем сравнительного богословия 3 курса; 46 тем сравнительного богословия 4 курса; 12 тем нравственного богословия; 10 тем искусства и полный конспект; 39 тем истории Церкви; 55 основных и 35 прежних материалов НРД; 44 темы права и дополнительные тексты.
- Все нераспределённые ранее предметы отнесены к 4 курсу по расписанию. Материалы 1 и 2 курсов не перенесены; ведомость и контакты студентов исключены.
- Локальный статический проект без зависимостей, API и базы данных. Старый проект не изменён.

## Ограничения и решения

- У 25 предметов расписания пока нет переданных учебных текстов; они отмечены в каталоге.
- Исходные DOCX по догматике 3 курса не найдены среди проверенных файлов. Все 38 текстов из старого проекта перенесены. Подробности в IMPORT_REPORT.md.
- Репозиторий: https://github.com/VAtapin/pmds.git; отдельная ветка codex/study-materials. Пользователь указал домен pmds.atapin.de и корень документов pmds.atapin.de/dist; абсолютный путь не указан, deployment агентом не выполнялся.

## Проверки

- Сборка успешна: 33 предметные страницы, 274 учебные главы, 11 страниц документов, всего 47 HTML-страниц.
- Проверены 523 локальные ссылки и SHA-256 всех 17 исходных файлов; пропусков нет.
- Сверены 343 исходные записи: ответы, основные положения и ссылки на источники канонического права сохранены.
- В браузере проверены каталог 4 курса, поиск предмета по слову «искусство», поиск «палладион» в полном тексте (одна глава), сброс поиска и чтение полного конспекта.
- Локальная страница отвечает HTTP 200, аудиозапись поддерживает Range-запросы (HTTP 206, проверен диапазон 1024 байта).
- JavaScript прошёл node --check. Изменений в старом проекте нет.
