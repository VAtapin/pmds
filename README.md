# Учебные материалы ПМДС

Самостоятельный локальный проект библиотеки для 3 и 4 курсов. Создан на основе сохранённых материалов проекта pmds и расписания дистанционного обучения на 2026–2027 учебный год. Исходный проект не изменяется.

## Запуск

Нужен Node.js 22 или новее. Сторонних зависимостей нет, `npm install` не требуется.

```powershell
npm run build
npm run check
npm run dev
```

Локальная ссылка: http://127.0.0.1:8767/

После сборки можно открыть `dist/index.html` прямо в браузере. Поиск, оглавление, документы и аудио работают без API и базы данных.

## Материалы

- 3 курс: 16 предметов расписания; готовые учебные тексты по догматическому и сравнительному богословию.
- 4 курс: 17 предметов; каноническое право, новейшая история Церкви, новые религиозные движения, церковное искусство, нравственное и сравнительное богословие.
- У остальных предметов сохранены сведения расписания и явно указано отсутствие учебных текстов.
- Главы открыты целиком. Исходные DOCX доступны как страницы для чтения и как файлы для скачивания. PDF открываются отдельно, запись лекции — в аудиопроигрывателе.
- Материалы 1 и 2 курсов не включены. Ведомость и контактный список группы не включены в сайт или репозиторий.
- Объём и сохранность переноса описаны в `IMPORT_REPORT.md`.

## Структура

- `content/library.json` — учебные главы, библиография, расписание 3 и 4 курсов, извлечённые тексты DOCX и сведения об исходных материалах.
- `materials/` — исходные учебные документы и аудиозапись. Файлы дедуплицированы по SHA-256; оригинальные названия сохраняются в библиотеке.
- `assets/` — оформление и браузерный поиск.
- `scripts/build.mjs` — независимая статическая сборка в `dist/`.
- `scripts/check.mjs` — проверка структуры, объёма переноса и локальных ссылок.
- `scripts/serve.mjs` — локальный сервер с поддержкой перемотки аудиозаписи.
- `dist/` — результат сборки, не хранится в Git.

## Публикация в Plesk

Самостоятельный проект находится в репозитории `https://github.com/VAtapin/pmds.git`, ветка `codex/study-materials`. История этой ветки независима от старого сайта; для установки нового сайта нужно клонировать именно её.

Открыть терминал в пустой папке `httpdocs` нового сайта и выполнить:

```bash
export PATH="/opt/plesk/node/22/bin:$PATH" && \
git clone --single-branch --branch codex/study-materials https://github.com/VAtapin/pmds.git . && \
npm run build && \
npm run check
```

В настройках хостинга Plesk установить корень документов нового сайта: `httpdocs/dist`. Это каталог готового сайта; исходники и материалы сборки находятся уровнем выше. PHP, Composer, база данных, миграции и установка npm-зависимостей не требуются.

Для обновления запустить из той же папки репозитория:

```bash
export PATH="/opt/plesk/node/22/bin:$PATH" && \
git pull --ff-only && \
npm run build && \
npm run check
```

Абсолютный путь нового сайта и его домен пока не указаны. Команды выполняются из выбранной папки нового сайта; Git commit и push сами по себе не являются публикацией на сервере.
