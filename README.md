# Учебные материалы ПМДС

Самостоятельный локальный проект библиотеки для 3 и 4 курсов. Создан на основе сохранённых материалов проекта pmds и расписания дистанционного обучения на 2026–2027 учебный год. Исходный проект не изменяется.

## Запуск

Нужен Node.js 22 или новее. Сторонних зависимостей нет, `npm install` не требуется.

```powershell
npm run build
npm run check
npm run dev
```

Локальная ссылка: http://127.0.0.1:8767/

После сборки можно открыть `dist/index.html` прямо в браузере. Поиск, оглавление, документы и аудио работают без API и базы данных.

## Материалы и самостоятельная работа

- На сайте публикуются исходные лекции, первоисточники, программы, презентации, официальные вопросы преподавателей и литература.
- Банк готовых ответов и составленные по нему конспекты не выводятся на страницы для учащегося. Они сохранены в авторском архиве исходного проекта: `content/library.json` и `materials/`, вне `dist/`.
- Задания допускаются только из переданных материалов преподавателя. Собственные упражнения, проверочные вопросы и дополнительные требования не добавляются.
- По методике преподавания 3 курса добавлена полная автоматическая расшифровка лекции 23.09.2026: 915 фрагментов с временными метками, 12 частей для чтения. Требования к письменному уроку приведены дословными цитатами. Неточные слова автоматической расшифровки не исправлялись наугад.
- «Мои заметки» — пустое поле для собственного текста. Оно сохраняется в браузере и экспортируется в TXT; на сервер заметки не отправляются. Готовых ответов, оценивания и выдуманных заданий в этом поле нет.
- Если исходной лекции нет, это указано на странице предмета. Сохранённый готовый ответ не выдаётся за исходную лекцию.
- Материалы 1 и 2 курсов, ведомость и контактный список группы не включены в ученический сайт.
- Отчёт переноса находится в `IMPORT_REPORT.md`.

## Структура

- `content/library.json` — источники, расписание 3 и 4 курсов, полные расшифровки, дословные задания преподавателей; прежние ответы в `chapters` остаются авторским архивом и не публикуются.
- `documents[].access` — явный режим `student` или `author-archive`; в сайт попадают только источники `student`.
- `subjects[].lessons` — исходные лекционные тексты для чтения; `teacherAssignments` — цитаты требований с указанием исходного документа.
- `materials/` — все сохранённые исходные файлы; в `dist/materials` копируются только разрешённые для ученического сайта.
- `assets/` — оформление, поиск по источникам и локальные заметки.
- `scripts/build.mjs` — статическая сборка. Она полностью пересоздаёт только `dist/`, чтобы старые страницы и файлы готовых ответов не оставались доступными по прежним ссылкам.
- `scripts/check.mjs` — проверка структуры, доступа к исходникам, SHA-256, ссылок, полноты расшифровки и дословности требований преподавателя.
- `scripts/serve.mjs` — локальный сервер с поддержкой перемотки аудиозаписи.
- `dist/` — готовый ученический сайт, не хранится в Git. Публиковать нужно только этот каталог.

## Публикация в Plesk

Самостоятельный проект находится в репозитории `https://github.com/VAtapin/pmds.git`, ветка `codex/study-materials`. История этой ветки независима от старого сайта; для установки нового сайта нужно клонировать именно её.

Корень документов сайта в Plesk: `pmds.atapin.de/dist`. Репозиторий размещается непосредственно в каталоге `pmds.atapin.de`, без дополнительной подпапки.

Для первой установки открыть терминал в папке `pmds.atapin.de`, из которой пользователь уже убрал старые материалы, и выполнить:

```bash
git init && \
git remote add origin https://github.com/VAtapin/pmds.git && \
git fetch origin codex/study-materials && \
git switch -c codex/study-materials --track origin/codex/study-materials && \
export PATH="/opt/plesk/node/22/bin:$PATH" && \
npm run build && \
npm run check
```

`git init` подключает Git в существующем каталоге. Сборка создаёт готовый сайт в `dist/`. PHP, Composer, база данных, миграции и установка npm-зависимостей не требуются.

Для обновления запустить из каталога репозитория `pmds.atapin.de`:

```bash
export PATH="/opt/plesk/node/22/bin:$PATH" && \
git pull --ff-only && \
npm run build && \
npm run check
```

Абсолютный путь нового сайта и его домен пока не указаны. Команды выполняются из выбранной папки нового сайта; Git commit и push сами по себе не являются публикацией на сервере.
